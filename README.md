# Resevia AI Agent

The core "brain" behind the Resevia AI Receptionist.

## Overview
This repository contains the AI logic, voice processing, and calendar integration services for the Resevia platform.

## Technology Stack
- **Runtime**: Node.js / TypeScript
- **Database**: Supabase (Postgres)
- **Communications**: Twilio / Vapi.ai / WhatsApp Business API

## Getting Started
1. `npm install`
2. Create `.env` with Supabase and OpenAI credentials.
3. `npm run dev`
